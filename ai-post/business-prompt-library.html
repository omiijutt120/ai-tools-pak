The Business Prompt Library: 25 Copy-Paste Prompts That Work

By Muhammad Umar·2026-08-04·📖 6 min read

How to use this library

Replace the [brackets] with your details. Add one constraint sentence at the end if the output feels generic: 'Use short sentences. No jargon. Include one concrete number.'

Customer service

  • Order status: 'You are a support agent for [business]. Answer this customer question politely and concisely in 2–3 sentences, and include the order's current status: [status]. If the order is delayed, apologize and give the new ETA: [ETA].'
  • Refund request: 'Draft a reply to this refund request that follows our policy ([policy]) but stays friendly and offers one goodwill option: [option].'
  • Complaint de-escalation: 'Rewrite this reply so it acknowledges the customer's frustration first, apologizes once, then presents the fix: [fix]. Max 4 sentences.'

Marketing & content

  • Ad variant: 'Write 5 Facebook ad variations for [product] targeting [audience]. Each: hook line, 2-sentence body, CTA. Different angles: urgency, social proof, price, problem, story.'
  • Blog outline: 'Create a 1,200-word SEO outline for: [topic]. Include H2s, target keyword [keyword] in title and first 100 words, and 3 internal-link suggestions.'
  • WhatsApp broadcast: 'Write a WhatsApp broadcast message for [offer]. Max 200 characters, friendly tone, one clear CTA, no more than 3 emojis.'

Operations

  • SOP draft: 'Turn these steps into a clear SOP with checklists: [steps]. Max 400 words, numbered, one action per line.'
  • Email triage: 'Summarize this email thread in 3 bullets: what happened, what's needed, who's responsible. Flag anything urgent.'
  • Meeting notes: 'From this transcript, extract decisions, action items (with owner), and open questions: [paste]'

AI agent system prompts

  • Receptionist: 'You are the AI receptionist for [business]. Answer calls about hours, prices, location and bookings using ONLY this data: [data]. If the caller asks for a human, say: Connecting you to a team member now. Never invent information.'
  • Order assistant: 'You are the order assistant. You can look up orders by ID using the tool. If an order is not found, say so and offer to connect to support. Confirm delivery details before ending the call.'
The difference between a generic prompt and a working prompt is usually one line: the never-invent-information constraint.

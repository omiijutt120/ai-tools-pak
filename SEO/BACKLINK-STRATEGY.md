# Ethical authority-growth strategy

## Objective

Earn relevant, indexable editorial and resource links by making AI Tools Pak useful to Pakistan-focused AI buyers, publishers and startup communities. The primary link target is the [AI Subscription Price Index Pakistan](https://aitoolspak.tech/ai-subscription-price-index-pakistan/); homepage links are appropriate only for brand/entity listings.

## Quality model

Each prospect is scored out of 100: relevance (30), editorial quality (25), geographic/topical fit (20), acquisition feasibility (15), and indexability (10), minus spam risk. Scores below 40 are rejected. Metrics such as DR or traffic are left as `not collected` until checked in a licensed tool; they are never guessed.

## Target-page mix

| Target | Purpose |
| --- | --- |
| Price Index | Data citations, resource pages, PR |
| Homepage | Accurate company, startup and directory profiles |
| Guides/comparisons | Contextual editorial links only |
| Product pages | Only when a publisher discusses that exact plan |

## Operating rules

- No PBNs, automated comments, bought editorial links, fake profiles or mass submissions.
- Human approval is required before any outreach or submission.
- Record a link as acquired only after `scripts/check-backlinks.js` verifies it live.
- Use branded and natural anchors; commercial exact-match anchors remain a minority.

## First 30 days

1. Submit the four manually qualified directories and save resulting URLs in the tracker.
2. Send the five personalized drafts in `OUTREACH-PIPELINE.csv`, one by one, after checking each contact route.
3. Publish monthly price-index updates only when catalog data changes.
4. Add 10–15 manually vetted prospects per week, rejecting low-quality directories.
5. Check verified links monthly and record changes with the tracker script.

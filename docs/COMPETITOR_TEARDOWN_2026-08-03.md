- **Stack:** WordPress + WooCommerce behind Cloudflare. Yoast-style XML sitemap index.
- **Structure:** thin. Only 3 real categories (`community-events`, `product-thinking`, `uncategorized`); every AI product filed under `uncategorized`.
- **Home:** title `Home - AI Wala`; meta description: `Excellent 4.9/5` (weak).
- **Product pages:** real, crawlable `/product/{slug}/` URLs (e.g. `/product/claude-ai/`). ~50 products in sitemap, 58 blog posts.
- **Schema:** homepage has Organization ("AI Wala") + Person ("Umair Abubakkar") + WebSite/WebPage + SearchAction. Claude product page emits **Product** schema with PKR **5000** price, visible WooCommerce price markup (₨3,500).
- **GEO/AEO:** `llms.txt` **absent**. No FAQPage schema found. No price/date freshness markers.
- **Trust:** WhatsApp present (+92 316 4449935 via click-to-chat), contact/about/shop/checkout pages.
- **Rating claim:** "Excellent 4.9/5" static text (no verifiable aggregateRating schema signal — likely a stored/imaginary rating).
